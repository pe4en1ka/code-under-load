# Проверка перед защитой

## Автоматические проверки

Выполнить `npm run check` и `npm test` из корня проекта.

## Ручная проверка в VS Code

1. F5 → открыть `examples/algorithms.cjs` в новом окне.
2. Запустить команду; указать `uniqueSlow, uniqueFast` и `100, 1000, 5000, 10000`.
3. Выбрать случайный массив. Проверить две линии и 8 строк таблицы.
4. Переключить логарифмическую шкалу n, навести курсор на точку.
5. Сохранить JSON и CSV. Сверить медиану в таблице и экспорте.
6. Повторить с одной функцией и одним размером: график должен показать одну точку.
7. Для `examples/custom-input.mjs` выбрать `linearSearch, binarySearch`
   и генератор «Свой генератор».
8. Ввести отсутствующее имя экспорта: должно появиться понятное сообщение об ошибке.
9. Ввести размеры `100, abc`: запуск должен быть отклонён.
10. Запустить тяжёлый эксперимент и нажать отмену в уведомлении.
11. Для бесконечного цикла из `test/fixtures/hangs.cjs` указать `hang`
    и тайм-аут 1 с. Редактор должен остаться отзывчивым.

Автоматические тесты не заменяют проверку интерфейса в Extension Development Host.

и регистрацию расширения, а не клики по диалогам.

## Версия 0.2.0

Для Python повторить основной сценарий с `examples/algorithms.py`, функциями
`unique_slow, unique_fast`, случайным массивом и размерами `100, 1000, 5000`.
Для своих аргументов выбрать `examples/custom_input.py`, функции
`linear_search, binary_search` и «Свой генератор».

Для C++ использовать `examples/algorithms.cpp` с `unique_slow, unique_fast`,
затем `examples/custom_input.cpp` с `linear_search, binary_search` и своим
генератором. Проверить этап компиляции в уведомлении, подпись C++ в отчёте,
сохранение результатов и понятную ошибку при неверном пути компилятора.
Файл C++ может содержать main; для замера выбирается отдельная функция. Для Python проверить путь к нужному
виртуальному окружению. Встроенные примеры не требуют сторонних библиотек.

Полный ручной проход диалогов остаётся проверкой при установке. Автоматические
тесты запускают реальные Python/GCC-процессы и проверяют их результат, ошибки,
отмену, тайм-аут, аргументы, функции void и сохранение поддержки JavaScript.

## Версия 0.2.1

Файл с main() или main(int, char**) включается через временный макрос переименования.
Тесты проверяют успешные замеры соседней функции, отсутствие вызова пользовательского
main (он завершил бы процесс с кодом 98/99) и неизменность исходного файла.
Встроенный генератор по-прежнему передаёт в выбранную функцию массив; наличие main
не меняет контракт аргументов.
